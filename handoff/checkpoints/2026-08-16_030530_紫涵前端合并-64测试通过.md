## 当前唯一进行中事项

用户手动烧录与实机验收：

1. T5 烧录 QIO 固件，保存 `460800` 完整串口日志，取得 T5 IP，Chrome 直连验证 `/stream` 与 `/snapshot`。
2. ESP32 烧录 self-test merged 固件，确认“我已开机”和 heartbeat。
3. ESP32 烧录 control merged 固件，先用串口 `1/2/3/3/4` 测试，无需接传感器。
4. Mac 启动桥接，完成 T5 + ESP32 + Chrome + Mac 麦克风联调。

详细操作见 [`../使用说明.md`](../使用说明.md)。

## 下一模型禁止猜测的内容

- T5 固件虽已编译，尚未在这块实板上验证 OV2640 出流。
- PDF 原理图的核心符号写作 `XH-WB5E`；具体商品模组是否为 `T5-E1/T5-E1-IPEX` 仍需实物丝印或供应商信息确认。
- 原理图中的板载能力不代表当前固件已实现。T5 麦克风、扬声器、屏幕、触摸、TF 写卡和传感器均需独立测试。
- GPIO18/19 同时连接 TF 卡 D2/D3 与 PWM 接口；当前 SDIO 启用时禁止把它们当 PWM 使用。
- 原理图与 BSP 对 LCD/触摸复位引脚存在差异，第一次启动必须保存外设注册日志。
- ESP32 两份固件虽已编译，尚未由用户烧录。
- Chrome 真机麦克风、MediaRecorder 和最终 WebM 尚未实测。
- 旋钮、敲击传感器尚未接线，P0 联调先使用串口命令。
- 不要代用户烧录，不要自动改变 Wi‑Fi，不要公开本地热点凭据。
