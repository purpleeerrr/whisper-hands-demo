# 产品与范围

## 产品判断

现有陶艺记录 App 已证明创作者愿意保存照片、泥料、釉料、层数、烧制和结果。它们的大部分输入发生在作品完成后。絮手将入口放在制作过程中的关键变化，并为不同工艺提供可复制和修改的记录模板。

公共专业资料与个人实验经验需要分开：参考架提供来源、变量和适用范围；个人实验库保存用户自己的材料、环境、观察和结果。Demo 不做工艺诊断。

## 本版包含

- 三套官方模板：陶艺釉料测试、水彩配色实验、玻璃烧制记录；
- 模板选择、复制、字段编辑，以及用复制模板建立工作台；
- 自由语音入口：先完整口述，再由本地规则整理候选结构，并允许保存为可编辑模板；
- 短按留画面、长按说观察；原始声音、转写和媒体进入过程收件箱；
- AI 或规则生成事实候选，用户编辑确认后入库；
- 事实确认后，由用户主动调用轻量 Meaning Layer，并复核意义候选；
- 陶艺模板下的参考架；
- 一次“选择相同釉料 → 找回已确认经验”的回顾；
- 网页模拟按键与实体键共用同一种事件。

## 本版暂缓

- 外部模型动态生成专业模板字段；
- 连续录制、动作识别和工艺诊断；
- 社区、共享知识库、账户和订阅；
- 主动语音打断和摄像头推断意图。
- 完整创作者访谈、完整个人意义档案、Story Studio 与跨项目意义搜索。

## 模板模型

用户可以从官方模板开始，也可以先完整口述，再把系统整理出的候选结构保存成模板。每个模板包含：

- 字段：例如泥料、釉料、层数、结果；
- 阶段：例如上釉、等待烧制、记录结果；
- 回顾条件：例如选择“海军蓝亮釉”时查找已确认记录；
- 参考架：与该工艺相关、有来源的阅读卡。

陶艺模板是主演示，包含事实确认、Meaning Layer 和材料触发回顾。水彩和玻璃模板可以复制、修改字段、建立工作台并进入过程收件箱；现场无需重复演示它们的完整闭环。

个人实验库按事实记录、创作原则和找回线索分层。事实来自用户确认的记录；原则来自用户主动调用并确认的 Meaning Layer；材料、画面和时间负责把旧经验带回当前情境。
