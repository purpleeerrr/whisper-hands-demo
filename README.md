# 絮手 Whisper Hands｜队友协作包

> 状态：2026-08-12｜本地 Web Demo 可运行，待队友 Review 与开发板真机验收

絮手是一套放在创作桌旁的过程记忆系统。创作者用适合自己工艺的模板记录关键变化；记录先进入过程收件箱，经本人确认后沉淀为个人实验库，并在下一次相关选择发生时被找回。

## 先用 30 秒理解本项目

陶艺釉料测试是现场完整跑通的第一套模板。产品长期面向各种实体创作：水彩、玻璃、树脂、首饰等，都可以通过模板加入。

```text
选专业模板 / 直接完整口述 → 短按留画面 / 长按说观察 → 过程收件箱 → 事实候选 → 用户确认
                                                               ↓
                                                         个人实验库
                                                   ┌───────────┴──────────┐
                                                   ↓                      ↓
                                        用户主动调用 Meaning Layer   相关材料触发回顾
                                                   ↓
                                             用户确认创作原则
```

硬件在 Demo 中承担一个很克制的角色：桌面实体键触发“留一刻”，给用户声光或触觉确认。它不负责判断用户在做什么，也不直接代替软件知识库。

当前 Demo 已包含：专业模板与“先说再整理”的自由语音入口；镜头拍照、3 秒视频或本地文件上传；本地原始录音与可编辑转写；事实确认后的轻量 Meaning Layer；事实／原则／找回线索三层个人实验库；用户设置的主动提醒；按画面相似度找回已确认记录；以及 Web Serial / F8 / F9 实体键接入方式。复制的模板和自由语音整理出的候选结构都可以保存为自己的模板。开发板固件、实际键位映射和板载麦克风仍需真机验收。

## 现场 Demo：90 秒故事

1. 选择「陶艺釉料测试」模板，新建“蓝色杯子试片”；
2. 填入白色炻器土、海军蓝亮釉、浸釉、第三层；
3. 短按留下当前画面，长按说“第三层釉料在杯沿堆积，下次先试两层”；
4. 原始声音、转写、画面和采集来源进入过程收件箱；
5. 系统整理出事实候选，用户确认后进入个人实验库；
6. 用户主动点击“提炼这次意义”，复核并确认一条创作原则；
7. 新建项目并再次选择「海军蓝亮釉」；
8. 页面展示“你曾在相同釉料上留下 1 条经验”，用户查看、忽略或关闭提示。

演示数据、页面状态和验收条件详见 [Demo 设计](./docs/DEMO_DESIGN.md)。

## 使用方式

运行 Demo 只需要 Python 3 和现代浏览器；Node.js 用于执行自动测试。推荐 Chrome / Edge，以便测试 Web Serial、摄像头和麦克风。

1. 队友先读 [V3 收敛方案](./项目资料/00_现行版本/01_选题与用户验证/絮手_选题收敛方案_V3.md)，再读 [市场研究](./项目资料/00_现行版本/02_市场与商业化/) 和 [用户研究](./项目资料/00_现行版本/01_选题与用户验证/)；
2. 开发成员接着读 [技术规格](./项目资料/00_现行版本/03_软件架构/docs/technical-spec.md)；
3. 按 [团队待办](./docs/TEAM_TODO.md) 认领工作；
4. 在仓库根目录运行 `npm start`；没有 Node.js 时运行 `python3 -m http.server 4173 -d app`；然后打开 `http://127.0.0.1:4173/`；
5. 每完成一个事项，同步更新 [项目待办](./项目资料/00_现行版本/00_项目待办.md) 与团队待办。

`app/index.html` 中的所有项目文件仍使用相对路径。直接双击打开只适合查看静态页面；镜头、麦克风、语音转写、系统通知和 Web Serial 需要 `localhost` 的浏览器权限环境。Chrome / Edge 支持 Web Serial；F8 短按留画面，按住 F9 说观察，松开结束。

`项目资料/00_现行版本` 是主资料的独立副本，包含研究原文、证据快照和当前方案。根目录 `docs/` 用于把队友最常用的信息快速提炼出来。
