# Demo 设计｜页面与数据

## 页面

| 页面 | 用户动作 | 页面必须展示 |
|---|---|---|
| 模板页 | 选择开始方式 | “直接开始说”自由入口；陶艺、水彩、玻璃模板卡；陶艺标注“完整 Demo” |
| 自由语音工作台 | 长按说完整记录 | 无需预设字段；提示可混合口述材料、动作、变化、模糊判断和下一步 |
| 工作台 | 建项目、填字段、短按留画面、长按说观察 | 项目名、字段、阶段、镜头预览、录音状态、网页模拟按键、硬件连接状态 |
| 过程收件箱 | 查看原始片段 | 时间、原始录音播放器、转写、图片／视频、采集来源、等待整理状态 |
| 事实候选页 | 编辑并确认 | 模板字段、观察、证据来源、确认／稍后／删除 |
| 个人实验库 | 查看分层经验 | 事实记录、创作原则、找回线索；原则可回链到对应事实 |
| 意义复核卡 | 主动提炼一次意义 | 一个反思问题、一条意义候选、证据引用、保留／修改／稍后／放弃 |
| 参考架 | 打开资料卡 | 资料标题、来源、适用范围，不给工艺诊断 |
| 找回提示 | 查看、忽略或关闭 | 为什么出现、匹配字段、旧记录摘要和三个操作 |
| 主动提醒 | 给已确认记录设回看时间 | 到时主动出现、说明触发来源、可完成 |
| 视觉找回 | 上传一张查询图 | 按本地画面相似度排序的已确认记录 |

### Meaning Layer 演示数据

事实确认后，记录卡显示“提炼这次意义”。用户点击后生成：

- 反思问题：你为什么决定先减少层数？
- 候选意义：我会先用更小的变量变化验证材料边界。
- 证据：本次已确认观察、施釉层数和原始语音。
- 状态：等待用户保留、修改、稍后处理或放弃。

### 自由语音整理演示数据

口述：“我用了白色石器泥，刚刚刷了三层蓝釉。杯沿好像有点太厚，我也说不上来，下次想先试两层。”

本地规则整理为“材料与对象、做了什么、观察与变化、模糊与不确定、下一步”五类候选。用户可以修改、确认入库，也可以把这套结构保存为可编辑模板。外部模型尚未接入，页面不得把规则结果描述成成熟的专业 AI 推理。

## 最低验收

- 90 秒内完整走通一次；
- 不接硬件时，网页短按／长按模拟按钮仍能完成记录；
- F8 短按模拟留画面；按住 F9 开始说观察，松开 F9 结束；
- Meaning Layer 在事实确认前没有调用入口；
- AI、摄像头或语音故障时，原始文字仍可确认入库；
- 回顾只匹配已确认记录；
- 同一事件重复发送时只生成一条收件箱记录。
- 自由语音入口无需预先配置字段；整理出的结构可编辑并可保存为模板。

## 能力边界

- 主动提醒由用户设置的时间或明确模板字段触发，不让镜头猜测用户意图。
- 视觉找回当前使用本地感知哈希，适合找相同或构图接近的过程图。它还不理解“流釉”“气泡”等工艺语义，语义视觉检索可在后续换成 CLIP 类图像嵌入。
- 媒体存在当前浏览器本地，单个文件限 3 MB。Demo 不上传云端。
- AI Keyboard 板载麦克风尚未通过真机验证。当前 Demo 用实体键触发电脑／USB 麦克风，页面显示真实采集来源。
- Meaning Layer 使用窄接口和可替换适配器。黑客松演示允许本地规则候选；接入外部模型前需另行确认隐私范围和服务配置。
