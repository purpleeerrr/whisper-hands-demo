# 絮手 Whisper Hands 技术交接

项目定位：手工艺人创作过程的记忆体——记录分叉、暂停、折返、搁置等中间状态，不只存最终成品。

***

## 一、文件 & 模块（6 个 JS，放 app/ 目录）

```
app/
├── 模块1：知识库（5 个）
│   ├── kb.js              ← 入口，所有操作从这里 import
│   ├── storage.js         ← IndexedDB 存储（不用直接 import）
│   ├── semantic-search.js ← 搜索（不用直接 import）
│   ├── visual-parser.js   ← 两帧画面帧差（需要再 import）
│   └── mock-data.js       ← 测试假数据（测试用）
└── 模块2：桌面叠层识别（1 个）
    └── desk-layer-analyzer.js  ← 入口，识别新增/移除/移动/替换/覆盖
```

**两个模块关系：完全独立**，可以只用任意一个。要对接时，把模块 2 的 `e.description` 直接传给模块 1 的 `saveSnapshot({ visualChange: e.description })`。

// visual-parser.js 是早期简易帧差，已被 desk-layer-analyzer.js 取代。新对接直接用 desk-layer-analyzer.js，visual-parser.js 保留不删但不需要 import。

***

## 二、注意事项（开始前看）

1. **不改 app/ 下这 6 个文件**，只改页面级 HTML/JS/CSS。
2. 页面必须跑在 localhost 或 https 下，不要用 file:// 双击。
3. 数据在浏览器本地（IndexedDB），不要用无痕模式，不要清缓存，不要换电脑演示。
4. 浏览器用 Chrome/Edge 100+。

# 模块 1：知识库（存项目 / 搜项目 / 导出）

## 用法

### 1. 初始化（页面加载调一次）

```js
import { initKB } from "./app/kb.js";
await initKB();
```

### 2. 灌测试数据（开发时用，只调一次）

```js
import { seedMockData, clearMockData } from "./app/mock-data.js";
await seedMockData();   // 灌 3 条项目
// await clearMockData(); // 清空重来
```

### 3. 使用接口

| 要做什么            | 调用                                             | 说明                                                                                               |
| --------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 开始创作，建项目        | `createSession(name, mode, tags)`              | 返回项目对象，拿到 `id` 后面用                                                                               |
| 存一条素材（截图/录音/录像） | `saveSnapshot(sessionId, fileData)`            | `fileData = { type, blob, note?, transcript?, visualChange? }`；`type` ∈ image/video/audio/marker |
| 搜项目             | `searchProjects(query)`                        | 返回数组，每项带 `_score` 和 `_layer`（L0 今天 / L1 近 7 天 / L2 7 天前）                                         |
| 拿列表             | `getAllProjects()`                             | <br />                                                                                           |
| 拿项目详情（素材列表）     | `getSessionDetail(id)`                         | `files` 已按时间排序；图片/音视频用 `URL.createObjectURL(file.blob)` 渲染                                       |
| 导出 Markdown 报告  | `exportMarkdown(sessionId)`                    | 自动触发浏览器下载，失败不会崩溃                                                                                 |
| 删除项目            | `deleteProject(sessionId)`                     | 调用前记得 confirm()                                                                                  |
| 检查是否就绪          | `isKBReady()` / `isSemanticReady()`            | 做 loading 用                                                                                      |
| AI 复盘取历史上下文     | getLayeredContext(sessionId)                   | 返回 `{l0, l1, l2}`，给 meaning.js 用                                                                 |
| 保存 AI 复盘结果      | updateSessionInsights(id, summary, principles) | meaning.js 生成后调                                                                                  |

### 4. 常见问题

- 语义模型是英文的，中文靠关键词兜底。搜项目名/标签内的关键词或用英文（vase/pottery/collage）可实现语义相近的模糊查询。
- 假数据的详情页图片不显示、音视频不播：正常。mock-data.js 的文件 `blob` 是 null（为了测试包小）。真实 `saveSnapshot` 保存的没问题。
- 刷新后数据没了：检查是不是用了无痕模式。
- 现场没网：只要提前开一次页面让模型进浏览器缓存就行，没加载成功也能自动降级为关键词搜索。

# 模块 2：桌面叠层识别（物料空间关系变化）

## 它做什么 / 不做什么

只识别 5 种空间叠层变化：**新增 ADD / 移除 REMOVE / 移动 MOVE / 替换 REPLACE / 覆盖 COVER**。

不识别：上釉/打磨等语义动作，不识别物料是什么东西（杯子/盘子等）。

会自动过滤：手晃过、光线突变、猫走过、摄像头被碰——这些都不会触发事件。

## 用法

### 1. 实例化 + 循环推帧

```js
import { createDeskAnalyzer } from "./app/desk-layer-analyzer.js";
const analyzer = createDeskAnalyzer();   // 只实例化一次

// 视频 loop 里每帧推一次，<video> / <canvas> / <img> 都行
function loop() {
  const evts = analyzer.pushFrame(document.querySelector("video"));
  // evts 是数组，没变化就是空
  requestAnimationFrame(loop);
}
loop();
```

### 2. 监听事件 + 和知识库对接（核心 3 行）

```js
analyzer.onEvent(async (e) => {
  // e.type: ADD / REMOVE / MOVE / REPLACE / COVER
  // e.description: 现成中文句子，直接填 visualChange
  // e.bbox: { xPct, yPct, wPct, hPct, areaPct }
  // e.layer: 推断的物料层级（0=最下，1/2/3=上）

  // 截图 + 存知识库：
  const canvas = document.createElement("canvas");
  canvas.width = videoEl.videoWidth; canvas.height = videoEl.videoHeight;
  canvas.getContext("2d").drawImage(videoEl, 0, 0);
  canvas.toBlob((blob) => saveSnapshot(currentSessionId, {
    type: "image", blob, visualChange: e.description
  }), "image/jpeg", 0.8);
});
// 录音
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const rec = new MediaRecorder(stream);
const chunks = [];
rec.ondataavailable = e => chunks.push(e.data);
rec.onstop = () => saveSnapshot(sessionId, {
  type: "audio", blob: new Blob(chunks, { type: "audio/webm" }), transcript: ""
});
rec.start();  // rec.stop() 结束
```

### 3. 调试（必开，不用写 UI）

传任意父 DOM，面板自己渲染 6 视图 + 6 滑杆，实时调参：

```js
analyzer.enableDebug(document.body);
```

调参速查：

| 问题          | 调哪个                              | 怎么调            |
| ----------- | -------------------------------- | -------------- |
| 手晃过还触发      | 稳定帧数                             | 调大（4 → 6-8）    |
| 光线变化误触发     | 像素差阈值                            | 调大（22 → 30+）   |
| 物料放很久才识别    | 稳定帧数                             | 调小（4 → 2-3）    |
| 一点点小变化就疯狂触发 | 块前景阈值                            | 调大（0.45 → 0.6） |
| 物料和桌面颜色接近   | 像素差阈值                            | 调小（22 → 12）    |
| 想识别很小的物料    | 实例化时传 `gridCols:24, gridRows:18` | <br />         |

### 4. 两帧一次性对比（没有实时视频时用）

```js
import { analyzeDeskChange } from "./app/desk-layer-analyzer.js";
const events = analyzeDeskChange(prevCanvas, currCanvas);
```

### 5. 常见问题

- 事件不对/不触发：先开 `enableDebug` 看前景掩码和稳定块，90% 的问题看一眼就知道调哪个滑杆。
- 摄像头被碰了/光突然变：设计上会直接丢弃不触发，连续 10 帧异常会自动重置背景，不用手动处理。
- 灯照一半亮一半暗：像素差阈值拉到 35+，或让光照更均匀。
