# 絮手 Whisper Hands｜选题收敛方案 V2

## 1. 建议：先做“创作过程实体书签”的需求证据，暂缓完整知识库硬件和实物测试

亚马逊消费品机会调研给出 22/35 的探索性评分。相邻需求已有购买证据，专用整机的购买理由仍缺少直接证据。当前实物测试条件不稳定，下一步应先用深度访谈和公开用户反馈补齐“谁在何时愿意为过程记录改变行为”的证据，再决定是否投入原型。

相对于最初的 V2.2 和上一轮收敛，本版做出以下调整：

| 原方案或上一轮设想 | 本版处理 |
|---|---|
| 面向所有艺术与手工创作者 | 首轮研究聚焦陶艺／釉料测试创作者；其他门类只保留为待验证扩展 |
| 连续观察并自动理解创作动作 | 用户用实体键主动标记；画面变化检测只作可删除的辅助节点 |
| 第一版同时完成记录、知识库和主动提醒 | 第一版只验证记录与回看；个人知识库和主动召回需要在用户确实复用记录后继续开发 |
| 以“AI 创作智能体”解释产品 | 以“创作过程实体书签”解释产品，降低教育成本和技术承诺 |
| 预设一体式摄像硬件 | 以桌面俯拍相机＋“留一刻”实体键为主体；镜头、支架与屏幕的集成度由行为与价格证据决定 |
| 重点询问材料失败是否很痛 | 先追溯真实记录、漏记和找回经历，再观察手机方案在哪一步失败 |
| 用知识库平台和长期数据价值讲商业故事 | 先证明一个动作能够持续发生，并能产生可找回的过程记录 |

**一句话方案：** 絮手是一枚放在创作桌上的“过程书签”。短按保存这一刻前后的画面，按住说一句修改原因，创作结束后得到一条可搜索、可回看的过程时间线。

当前决策门槛是确认“留一刻”对应的是高频且代价明确的真实节点，且手机＋俯拍架＋录音备忘录存在可重复描述的断点。实体键能否形成稳定行为，留到实物可用后验证。

## 2. 已知、假设与开放问题

| 类型 | 结论 | 证据或处理 |
|---|---|---|
| 已知 | 俯拍记录存在成熟购买需求 | 支架约 $20–40；文档摄像头约 $50–190；Logitech Reach 证明部分创作者会为优质俯拍结构支付更高价格 |
| 已知 | 用户会为可靠实体快捷操作付费 | Stream Deck 等品类已形成货架与品牌心智 |
| 已知 | 陶艺／釉料测试需要记录配方、阶段、图片和结果 | 行业资料、社区行为和多款垂直 App 共同支持 |
| 已知 | 市场替代方案便宜且丰富 | 旧手机／现有手机＋俯拍架＋相机／录音／笔记工具即可完成基础记录 |
| 已知 | 摄像头、俯拍架、快捷键和创作记录 App 均较拥挤 | 单一硬件参数或通用快捷键难以形成优势 |
| 假设 | 用户会在创作过程中自然按键标记关键节点 | 需要真实任务观察，不能由访谈态度代替 |
| 假设 | 前后画面＋一句原因比纯录音更容易找回经验 | 需要 A/B 对照与延迟回看测试 |
| 假设 | 实体键节省的步骤足以支持 $39–69 的附件价格 | 需要价格选择、预订或可退订金验证 |
| 开放 | 一体机是否成立 | $149–249 只作为概念测试区间；画质、结构、隐私、BOM、售后和软件寿命尚未核算 |

“context＋录音＋总结＋提醒”已经进入拥挤市场。Plaud、Limitless、Notion AI及大量 RAG 工具覆盖语音、转写、摘要和知识检索，Looki 等设备继续扩展视觉与生活上下文。公共陶艺／玻璃／水彩知识也容易被通用模型和垂直 App 覆盖。

絮手当前可争取的差异集中在两个动作：双手忙碌时快速给现实过程打书签；保留被覆盖、替换和废弃的中间版本。个人知识库只有在用户持续记录、回看和复用后才会自然形成。主动提醒需要可靠的材料、项目或时间触发，也需要先证明用户希望旧记录在这些时刻出现。

## 3. 最小方案与版本边界

黑客松版本完成一条流程：开始创作 → 短按保存前后关键帧 → 长按录入一句原因 → 结束后按时间查看、搜索和导出。

第一版包含：开始／结束、实体标记、即时反馈、前后关键帧、短语音转写、过程时间线、搜索与导出。自动画面变化检测可以生成候选节点，默认静默，用户可以删除。

第一版暂缓：复杂动作识别、心流判断、跨工艺公共知识库、专业工艺建议、艺术评价、外部灵感推荐、主动打断、共享社区和订阅体系。

产品形态保留三条出口：

| 形态 | 测试价格 | 成立条件 |
|---|---:|---|
| 俯拍相机原型＋本地伴侣 | 暂不单独定价 | 用固定镜头与时间线验证用户是否回看过程；本地伴侣只负责存档、检索与导出 |
| 俯拍相机＋实体书签键 | $39–69 的附件级测试区间 | 实体动作明显减少漏记，用户接受外接镜头或自备手机作为早期画面来源 |
| 一体式创作记录相机 | $149–249 概念区间 | 开机即用、固定画面和统一体验产生足够价值，且成本与售后可控 |

## 5. 先完成的研究，再决定是否进入原型

先完成两类证据。

1. 访谈 5–8 名过去三个月有重复制作、材料测试或阶段复盘经验的创作者。以最近一次真实作品为线索，看到她们真实使用的照片、样片、纸本、App 或文件夹。
2. 收集并编码 30–50 条公开用户反馈。陶艺／釉料测试优先，补充桌面俯拍、模型、树脂和手工记录社区。每条保留链接、日期、场景、当前做法、具体阻力和反证。

只有当两类证据反复出现同一个断点，才进入原型。优先寻找四个信号：中间状态确实会丢；现有记录在手脏、双手忙或专注时被放弃；画面与一句原因需要被关联；固定镜头或一颗实体动作有合理的桌面位置。

若访谈和公开反馈都指向“手机＋相册／纸本已经够用”，或痛点只发生在极少数场景，先转向低成本的记录软件、拍摄辅助或另选问题。若它们都指向同一类高成本漏记，再制作最小原型。

原型通过线留作下一阶段使用：每次任务主动标记次数中位数达到 3；至少 60% 的标记包含可理解的修改原因；至少 70% 的参与者在任务后主动打开时间线；24–72 小时后的信息找回表现优于手机方案；至少两人愿意按目标价格预订、留下明确付费承诺或支付可退订金。

若用户很少标记或回看，项目应转向俯拍拍摄辅助或停止该方向。若时间线被持续使用、实体键增益有限，保留桌面相机，简化实体交互。若实体键显著减少漏记，继续验证 $39–69 的附件级方案。只有固定画面、开机即用和统一工作流共同产生明确价值，才进入一体机 BOM、结构、隐私、认证和 Amazon 量产研究。
