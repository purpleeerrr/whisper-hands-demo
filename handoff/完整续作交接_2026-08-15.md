# Whisper Hands 路演软硬件接入｜完整续作交接

## 1. 用户当前目标

为明日路演完成一条可离线运行的双板链路：

```text
T5 + OV2640 摄像头
  └─ Wi‑Fi MJPEG → Mac Node 本地桥接 → 最新网站实时画面
                                               ├─ Canvas 截图
                                               └─ Canvas + Mac 麦克风 → WebM

ESP32-S3 N16R8 + 旋钮/敲击/后续传感器
  └─ Wi‑Fi HTTP POST → Mac Node 本地桥接 → SSE → 网站四项控制
```

两块板分开烧录、分开 USB 供电，不直接互相连接。Mac 是中枢。用户已说明 T5 可用 TuyaTool 手动烧录，且旧测试固件已烧录成功。任何模型都不得代用户烧录；只交付 `.bin` 路径和手动步骤。

## 2. 固定产品事件

HTTP 端点：`POST /api/hardware/event`。

| 事件 | 产品语义 |
|---|---|
| `VIDEO_TOGGLE` | 开始录像／暂停／继续 |
| `SNAPSHOT` | 截取当前 T5 画面 |
| `AUDIO_MARK_START` | 标记重点语音区间开始，整场原声仍连续保存 |
| `AUDIO_MARK_STOP` | 标记重点语音区间结束 |
| `VIDEO_FINISH` | 结束录像并存档 |
| `MODE` | 旋钮只选择 1–4 功能，按下后才执行 |

旋钮模式：1 录像切换、2 截图、3 语音区间切换、4 结束。敲击次数同样映射 1–4。

## 4. T5 固件现状

TuyaOpen 仓库：`hardware/local-tuyaopen/`

### 4.1 主板一级资料

主板原理图已复制到 `hardware/docs/NICEMCU-T5-DEV_V1.2_原理图.pdf`，逐页核验结果位于 [`hardware/docs/NICEMCU-T5-DEV_V1.2_主板事实表.md`](../hardware/docs/NICEMCU-T5-DEV_V1.2_主板事实表.md)。下一位模型必须先读事实表，再判断 T5 引脚和能力。

关键事实：

- 原理图文件名为 `NICEMCU-T5-DEV_V1.2.SchDoc`，核心符号写作 `TUYA-T5 (XH-WB5E)`。PDF 本身没有确认 `T5-E1/T5-E1-IPEX` 商品型号。
- OV2640 使用 GPIO0/1 控制总线、GPIO27/29/30/31 时钟同步、GPIO32-39 数据。
- TF 卡使用 GPIO14-19；GPIO18/19 同时连接两个 PWM 接口。当前 SDIO 启用时禁止作为 PWM。
- 板上设计有 USB-C + CH340C、锂电管理、3.3V/5V、电池 ADC、OV2640、一个板载麦克风、扬声器功放、LCD/触摸、TF、SH3001、温度传感器、RGB、按键、LoRa 和 PWM 接口。
- `MP2/MN2` 接扬声器输出作回声参考，不能计作第二个独立麦克风。
- 原理图与当前 BSP 在 LCD/触摸复位和中断定义上有差异。当前 BSP 还会初始化 audio、button、display、touch、camera 和 SDIO，因此第一次 `460800` 启动日志必须完整保存。
- 原理图确认设计连线；器件是否实装、BSP 是否完全匹配、驱动能否运行仍需实板结果。
