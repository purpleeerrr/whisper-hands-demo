# 絮手 Whisper Hands｜选题收敛方案 V3

## 这次改动：从陶艺记录硬件，收敛为模板化的创作过程知识库

絮手服务实体创作者。陶艺／釉料测试作为第一套完整 Demo 模板，因为它有明确的变量、结果等待期和记录需求；水彩、玻璃、树脂、首饰等创作可以通过模板扩展进入系统。

相对于 V2，本版做出以下调整：

| V2 | V3 |
|---|---|
| 陶艺／釉料测试是唯一首轮方向 | 陶艺是首个验证模板；产品核心是可选择、可复制、可修改的创作模板系统 |
| 知识库和主动回顾暂缓 | 架构现在预留两者；Demo 只实现一条有限的主动回顾链路 |
| 时间线是主要产物 | 过程收件箱、候选记录、确认后的个人实验库构成完整记录闭环 |
| 公共陶艺资料是辅助内容 | 每个专业模板拥有独立的参考架；公开资料与个人经验分开显示 |
| 用户只能跟随既定字段 | 用户可选专业模板，也可先完整口述，再复核系统整理出的结构并保存为模板 |

**一句话方案：** 絮手是一套放在创作桌旁的过程记忆系统。它帮助创作者在关键时刻留下证据，用适合自己工艺的模板沉淀经验，并在下一次相关决定到来时找回那段经验。

## 为什么模板化知识库值得做

亚马逊调研所列的垂直软件已经验证了“按工艺管理个人经验”的需求：Perch Pot 支持作品照片、阶段、泥料、釉料和可自定义字段；ClayLab 覆盖施釉、泥料、烧制、尺寸和阶段追踪；Studio Journal 聚焦配方、烧制结果与工作室笔记；Glaizit 同时覆盖釉料组合、记录、灵感和社区；Pottery Glaze Test Tracker 提供试片、层数、温度、缺陷和搜索。

这些产品的共同限制也清楚：创作者通常在完成后手动补资料。絮手把入口放在制作中的关键变化。实体键与固定视角负责捕捉那一刻；模板负责把记录组织成适合某种工艺的经验；个人库负责让这段经验日后可找回；参考架负责提供可溯源的专业资料。

公共知识无法构成单独的壁垒。Glaizit 已经提供釉料、材料、灵感与社区内容，通用模型也可以回答大量基础问题。絮手的价值应落在“公共参考如何和我自己的材料、环境、试验结果连起来”。系统必须区分来源：参考架告诉用户通常需要关注什么；个人实验库告诉用户在自己的工作室里曾经发生什么。

## 最小产品：四层知识结构

```text
专业模板 / 自由语音入口
  ↓ 短按留画面 / 长按说观察
过程收件箱
  ↓ 转写 + AI 整理为事实候选
用户确认 / 编辑
个人实验库
  ├→ 用户主动调用 Meaning Layer
  │      ↓ 用户确认意义候选
  │   个人创作原则
  └→ 模板条件触发
     主动回顾 + 参考架
```

### 模板工作台

用户拥有两种开始方式。她可以选择官方模板，或复制模板后改字段、阶段和回顾条件；也可以直接进入自由语音记录，把材料、动作、变化、模糊判断和下一步一起说完，由系统整理为可编辑候选。黑客松版提供三套官方模板：

| 模板 | 关键字段 | 阶段 | Demo 状态 |
|---|---|---|---|
| 陶艺釉料测试 | 泥料、釉料、施釉方式、层数、烧制条件、结果 | 上釉、等待烧制、记录结果 | 完整跑通 |
| 水彩配色实验 | 纸张、颜料、配色、水量、技法、观察、结果 | 尝试、干燥、回看 | 可选择和复制 |
| 玻璃烧制记录 | 玻璃类型、拼接方式、温度曲线、退火、结果 | 制作、入窑、等待结果 | 可选择和复制 |

用户模板有两条生成路径。第一条是“复制后编辑”，用于已经知道结构的人；第二条是“先说再整理”，用于不想预先配置字段的人。黑客松 Demo 用本地规则把口述整理为“材料与对象、做了什么、观察与变化、模糊与不确定、下一步”五类候选，用户可逐项修改并把这套结构保存成模板。未来版本可把本地规则替换为模型适配器，动态生成更贴合具体工艺的字段。

### 过程收件箱

短按“留一刻”保存当前画面和时间；长按开始说观察，松开结束录音。过程收件箱同时保留原始声音、转写文字、画面、项目字段快照和采集来源。板载麦克风尚未通过真机验证时，AI Keyboard 只负责触发，电脑或 USB 麦克风负责采集，界面明确显示声音来源。

原始内容允许不完整、没有结果、没有标签。语音转写可以重录或修改，手动输入作为权限被拒绝、浏览器不兼容等情况下的降级入口。未经用户确认的素材不会进入个人实验库。

### 个人实验库

AI 或本地规则从原始内容中提出“候选记录”。专业模板按既定字段填充；自由语音入口先从完整口述中整理候选结构。用户可编辑、确认、稍后处理或删除。

个人实验库分为三层：事实记录保存用户确认的原始观察与证据；创作原则保存用户主动提炼并确认的意义；找回线索记录材料、画面与时间入口。原则始终回链到对应事实，找回结果也显示触发原因。

### Meaning Layer

Meaning Layer 位于事实记录之后。用户确认事实候选后，可主动点击“提炼这次意义”。系统只基于本次已确认事实、对应的声音／画面证据和用户已经确认过的个人创作原则，给出一个反思问题与一条意义候选，并标出证据来源。

意义候选支持保留、修改、稍后处理和放弃。确认后的内容进入“个人创作原则”，可以在未来回顾中作为第二层线索。事实记录始终单独保存；Meaning Layer 失败或用户跳过时，记录闭环仍然成立。黑客松版不推断情绪、性格或心理状态，也不自动生成公开叙事。

### 参考架与主动回顾

每套官方模板拥有一组人工选取、有来源的参考卡。陶艺模板可先放入“记录釉料测试变量”和“试片编号／结果对照”两张卡，并链接到 Ceramic Arts Network 等来源。参考卡只提供记录框架、来源和适用范围；它不对用户作品做诊断。

主动回顾由模板配置，不由摄像头自动判断。黑客松只实现：用户在陶艺工作台选择某种釉料后，系统从她确认过的实验库中找到相关记录，显示“为什么现在出现”。后续可增加用户设置的出窑日期提醒和项目打开时的未完成记录提醒。

## 黑客松 Demo：一条完整链路

1. 用户进入「陶艺釉料测试」模板，建立“蓝色杯子试片”项目；
2. 选择泥料和釉料，短按硬件留下当前画面；
3. 长按硬件说：“第三层釉料在杯沿堆积，下次先试两层”，松开后保存原始录音并生成转写；
4. 过程收件箱同时展示声音、转写、画面和采集来源；
5. 系统显示事实候选，用户确认泥料、釉料、层数、观察和“等待出窑结果”；
6. 事实记录进入「我的实验库」；
7. 用户主动点击“提炼这次意义”，系统给出一个反思问题和一条带证据的意义候选；
8. 用户确认或跳过意义候选；
9. 用户在新项目中再次选择同一种釉料；
10. 工作台出现一张提示卡：“因为你选择了这支釉料，找到了 1 条已确认记录”。

水彩和玻璃模板只需展示：可选择、可查看字段、可复制改名。它们不进入现场主演示，避免把 Demo 拆散。

## 当前范围与验证门槛

这版包含：模板选择、模板复制编辑、自由语音记录与本地规则整理、候选结构保存为模板、短按留画面、长按说观察、原始录音与转写、过程收件箱、事实候选确认、三层个人实验库、用户主动调用的轻量 Meaning Layer、模板字段筛选、陶艺参考架、一次材料触发的主动回顾、本地导出和网页模拟按键。

这版暂缓：由外部模型动态生成专业模板字段、完整创作者访谈、完整个人意义档案、Story Studio、跨项目意义搜索、连续录制、自动动作识别、AI 工艺诊断、情绪与性格推断、公开共享知识库、社区、外部灵感搜索、主动语音打断、订阅和账户系统。

模板化结构是产品决定；独立硬件购买理由仍是假设。访谈和实物测试需要继续验证：创作者是否会在过程中主动标记、前后画面和原因能否帮助找回经验、固定镜头和实体键是否能显著优于手机流程。
