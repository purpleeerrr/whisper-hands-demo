## 现场优先级

先保证：模板选择 → 留一刻 → 收件箱 → 确认入库 → 相同釉料找回。

摄像头、语音与外部 AI 整理属于可选增强。任何增强失败时，保留文字记录、本地规则整理和网页模拟按键，Demo 继续可运行。

## 本地 Review 清单

1. 在自己的电脑启动 `app/index.html` 所在的本地静态服务器；
2. 走完陶艺模板的“留一刻 → 整理并确认 → 开始下一次试片 → 选择深海蓝透明釉 → 找回经验”；
3. 打开水彩、玻璃模板；复制水彩模板并改一个字段名；
4. 记录浏览器、是否跑通、卡住步骤、截图或录屏和建议优先级。
5. 上传一张图或录 3 秒视频，确认媒体随记录入库；给记录设 5 秒提醒；用相似图跑一次视觉找回。
6. 打开“直接开始说”，确认无需配置字段；口述后检查候选结构并保存成模板。
7. 检查首页实验库预览的事实、原则、找回线索三层，并记录独立实验库仍缺少的列表、检索、详情与单条提炼体验。
