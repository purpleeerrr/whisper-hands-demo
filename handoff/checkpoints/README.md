# 节点存档规则

这里保存已经发生的重要节点快照。旧快照只追加，不覆盖。

必须存档的节点：

1. 固件编译与校验完成；
2. T5 手动烧录成功或失败；
3. T5 串口联网并取得 IP；
4. T5 实时画面连续 10 分钟；
5. ESP32 自检烧录和串口通过；
6. ESP32 控制固件烧录和串口指令通过；
7. ESP32 HTTP 事件驱动网站；
8. Chrome 生成带画面和原声的 WebM；
9. 完整演示连续通过三次；
10. 任何方向变化或降级决定。

每个快照要包含：发生时间、结果、验证证据、失败日志位置、下一动作、仍未知内容。不要把密码、授权码或私钥写进快照。
